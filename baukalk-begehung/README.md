# BauKalk Begehung (Konzeptskizze)

Klickbare Konzeptskizze einer Handy-App für Baustellenbegehungen, die ihre Daten an das Desktop-Programm BauKalk übergibt. Ausblick einer Masterarbeit.

Nicht umgesetzt: Die Seite rechnet nichts und speichert nichts. Alle Zahlen sind Beispielwerte.

Live: https://michigblino.github.io/Southbound/baukalk-begehung/

Eigenständig, unabhängig von Southbound: eigener Service Worker mit Scope `/baukalk-begehung/`, eigenes Manifest.

Installieren: Seite im Handy-Browser öffnen, dann „Zum Home-Bildschirm“ (iPhone, Safari, Teilen) bzw. „Zum Startbildschirm hinzufügen“ (Android, Chrome, Menü). Danach läuft sie auch offline.
