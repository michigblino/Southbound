# Band & Matte

Eigenständige Home-Workout-Web-App (2er-Split, Zirkel, Matte + Loop-Bänder).
Unabhängig von Southbound: eigener Service Worker mit Scope `/band-und-matte/`, eigenes Manifest.

- Live: https://michigblino.github.io/Southbound/band-und-matte/
- Installieren: Seite am Handy öffnen → „Zum Home-Bildschirm" (iPhone) bzw. „App installieren" (Android).
- Updates: `index.html` ändern und in `sw.js` die Cache-Version (`band-und-matte-v1`) hochzählen.
